# Weekly Weight Tracker

A mobile-friendly web app for tracking weekly medication dosage and daily weight.

## Features
- 💊 Track medication mg per week
- ⚖️ Log weight on selected weekdays  
- 📱 Mobile-optimized card layout
- 💾 Save/load data as JSON files
- 🔒 100% private - data stays on your device

## How to Use
1. Select which days to track weight
2. Click "Add week" to create a new week
3. Enter medication dose and daily weights
4. Save as JSON file for backup

## Live Demo
[Use the app here](https://millaw.github.io/weekly-weight-tracker)

## Local Development
Just open `index.html` in any modern browser.
